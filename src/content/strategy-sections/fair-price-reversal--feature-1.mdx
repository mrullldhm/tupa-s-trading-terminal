## Test every setting (F1)

This stage runs all 64 combinations of setup window, ATR move threshold and target for each session,
then selects separate winners for 13 metrics. Swing detection is fixed by `indicators/structure_swings.pine`
and is never searched. All results use limit entries and include commission with no added slippage.

These settings were selected on the same historical data shown here; the results are in-sample.
