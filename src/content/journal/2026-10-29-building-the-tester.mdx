---
title: Building a tester that behaves like TradingView
date: 2026-10-29
summary: Why I wrote my own backtester for CL1!, and how it copies TradingView's fill rules.
kind: milestone
---
TradingView's Strategy Tester is where most retail traders check an idea. It is good, but slow to run hundreds of
settings, and it only shows you the final numbers. I wanted the same numbers, for one market, that I can run in
bulk and check line by line.

So the tester does one thing: it copies how TradingView fills orders on **CL1!**, crude oil futures, on 1-minute
bars. An order placed at a candle's close fills on the next candle. Inside a candle, price is assumed to go open,
then the nearer extreme, then the other extreme, then close. Stops and limits fill the same way TradingView fills
them.

Every test uses the same fixed costs: $2.01 per order, 1 contract, $50,000 capital. The site displays baseline results after commission. Planned limit-entry strategy updates and new tests are pending.

Before any result counted, Codex reviewed the plan and the code. It found one high and eight medium problems in
the code review. All were fixed, each with a test. One rule is mine and not TradingView's: a trade still open on a
contract's last bar is closed there instead of being carried across the roll. It is labelled as such everywhere.
